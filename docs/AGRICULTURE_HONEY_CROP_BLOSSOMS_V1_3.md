# Floral honey v1.3 — crop-source coverage

The honey-source data is versioned to v1.0 and contains 38 bottle variants: 37 recognized source-specific routes plus neutral wildflower honey for sufficiently diverse mixed forage.

The v1.9 crop additions introduce jicama, adzuki bean, mung bean, cowpea, safflower, chicory, mustard greens and water spinach source routes. Each bottle has a registered item, a separate generated 16×16 bottle sprite, item model, bilingual display/effect text, nutrition/saturation values and a short fantasy gameplay effect. These are fictional game mechanics, not claims about real honey.

A dominant recognized source must meet the existing local-forage threshold. Sparse or uncertain forage still returns vanilla honey; sufficiently diverse mixed forage returns wildflower honey without a bonus effect. The bounded harvest-time scan avoids forcing unloaded chunks to load.
