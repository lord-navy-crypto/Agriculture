# Gugu Gaga 农业与蜂蜜完整玩法指南

适用版本：Minecraft 1.21.1 + NeoForge 21.1.x。本文描述的是当前主分支的实际代码规则；作物气候是游戏平衡模型，不等于真实世界温度模拟。

## 一、创造模式物品栏

模组内容集中在四个独立的 Gugu Gaga 创造模式标签中，不再插入原版的「原材料」「食物与饮品」或「工具与实用物品」标签：

- **Gugu Gaga：农作物与种子**：100 种作物的播种物、收获产物及农业材料。
- **Gugu Gaga：蜂蜜与授粉**：50 种特色蜂蜜、养蜂工具、蜂类标签与栖息地。
- **Gugu Gaga：料理**：农业料理、植物料理、油料及相关食品。
- **Gugu Gaga：海洋与真菌**：海洋植物、海产品、菌类培养物与菌类食品。

每个标签直接读取对应物品注册表，因此后续新增并注册的物品也会自动进入正确的标签，不需要再手工逐个加入原版分类。

## 二、作物完整生产周期

### 1. 获取种子

当前有 **100 种注册作物**，每种都有对应的种子物品和独立合成配方，配方文件名统一为 data/gugugaga/recipe/作物名_seeds.json。种子配方会使用原版植物、种子、农产品或其他适合的原版材料；输出物品均为对应的 gugugaga:作物名_seeds。

部分示例：

| 种子 | 合成原料 | 产出 |
|---|---|---:|
| 玉米种子 | 小麦种子 + 干草块 | 2 |
| 番茄种子 | 南瓜种子 + 甜菜根 | 2 |
| 草莓种子 | 甜菜根种子 + 甜浆果 | 2 |
| 水稻种子 | 小麦种子 + 海带 | 2 |
| 棉花种子 | 线 | 1 |
| 薰衣草种子 | 小麦种子 | 1 |
| 茶种子 | 绿色染料 + 小麦种子 | 1 |
| 咖啡种子 | 可可豆 + 小麦种子 | 1 |

完整配方以模组 JAR 内的 recipe JSON 为准；安装 JEI/EMI 等配方查看器时，也可直接在游戏内查看配方。

### 2. 播种与生长

1. 将种子用于可种植的耕地，种子物品本身就是对应作物的种植物品。
2. 作物有 8 个生长阶段，age 从 0 到 7；只有 age=7 才会掉落成熟农产品。
3. 生长速度受作物的气候分组与生长判定影响。分组包括 COOL、TEMPERATE、WARM、DRY 和 WET，是游戏内的相对环境规则。
4. 水稻需要附近淡水；芋头和西洋菜使用更紧凑的淡水检查范围。缺水时它们不会通过正常随机生长判定。
5. 每种作物都有独立的方块状态、阶段模型、种子图标、农产品图标、中英文名称和掉落表。

### 3. 授粉与额外产量

- 授粉组为 NONE 的作物不会获得蜜蜂授粉加成。
- ORCHARD 与 BERRY 作物可在开花阶段（age 4–6）被符合条件、携带花蜜且足够接近的蜜蜂授粉。
- 授粉不会直接让作物瞬间成熟；它记录在作物状态中，并可能在成熟收获时增加一份农产品。
- 重复采叶作物不获得人为增加的蜜蜂额外产量；重复采果、花或嫩茎的作物按各自规则处理。

### 4. 收获与再生

**普通作物：** 成熟后破坏作物方块，会获得种子；只有成熟状态才会掉落农产品。种子与农产品分别由掉落表处理。

**可重复采收作物：** 成熟时空手右键采收，植株保留在地里并回到 age=4，之后继续生长，不必每次重新播种。

- 果实／荚果类重复采收：番茄、黄瓜、草莓、蓝莓、甜椒、茄子、西葫芦、覆盆子、蔓越莓、秋葵、辣椒、四季豆、豌豆、西兰花、抱子甘蓝、棉花、南瓜、黑莓、黑加仑、佛手瓜、葡萄、甜瓜和西瓜。
- 叶片类重复采收：罗勒、薄荷、芝麻菜、瑞士甜菜、欧芹、羽衣甘蓝类叶菜、莳萝、香菜、白菜、莴苣、菠菜、羽衣甘蓝、芹菜、细香葱、菊苣叶、豆瓣菜、芥菜叶、空心菜、马齿苋、茶、芥蓝和长蒴黄麻。
- 花／花蕾类重复采收：薰衣草、三叶草和洋蓟。
- 嫩茎类重复采收：芦笋。

其余作物按普通破坏收获处理。自动化验收会逐一核对 100 种作物的种子配方、成熟掉落、模型、方块状态、气候映射及中英文名称。

## 三、蜂蜜：如何获得不同类型

特色蜂蜜不是在工作台里把花朵合成瓶装蜂蜜，而是在采蜜时，根据蜂巢周围已加载区域中的花源自动判定类型。

### 1. 建立可产蜜的蜂巢

使用原版蜜蜂巢或蜂箱，让原版蜜蜂正常采花并将蜂巢的蜂蜜等级积累到 5。模组的蜂类栖息地用于观察与授粉生态，不会自行产出蜂蜜；采蜜流程使用原版蜂巢／蜂箱。

### 2. 制作蜂蜜采集器

工作台配方：

|  | 原料 |  |
|---|---|---|
| 空 | 铁锭 | 空 |
| 木棍 | 蜂巢 | 木棍 |
| 空 | 铁锭 | 空 |

也就是 2 个铁锭、2 根木棍和 1 个蜂巢。

### 3. 安全采集

1. 在蜂巢正下方放置点燃且烟雾通畅的营火。
2. 等待蜂蜜等级达到 5。
3. 主手拿蜂蜜采集器，对原版蜂巢／蜂箱使用。
4. 正常模式需要一个玻璃瓶（副手或背包中均可），消耗玻璃瓶并获得一瓶蜂蜜。
5. 如果副手拿剪刀，则进入蜂巢模式，消耗 1 点剪刀耐久并获得 3 个蜂巢，不需要玻璃瓶。
6. 每次成功采集后，蜂巢的蜂蜜等级会重置为 0，需要蜜蜂再次积累。

蜂蜜采集器配方、蜂蜜等级、营火烟雾、玻璃瓶／剪刀分支和采集后重置都已加入自动化检查。

### 4. 如何指定特色蜂蜜

蜂蜜分类会在蜂巢周围进行一次有界采样：水平半径 5 格，垂直范围为蜂巢下方 2 格到上方 1 格，并跳过尚未加载的区块。

- **单一花源特色蜂蜜：** 某个已识别花源至少出现 6 次，并且占计入花源总数的至少三分之二，就会产出该花源对应的特色蜂蜜。
- **野花混合蜂蜜：** 没有单一花源达到主导门槛，但采样区内至少计入 12 份花源、并包含至少 3 种不同来源时，产出野花蜂蜜。
- **原版蜂蜜：** 花源稀少、来源不明确或不满足上述门槛时，回退为原版蜂蜜。

模组目前注册 **50 种蜂蜜瓶**：49 条明确的特色花源路线，加上野花混合蜂蜜。来源包括原版花朵以及三叶草、薰衣草、荞麦、向日葵、浆果、瓜类和其他授粉作物。成熟的模组作物（age 至少为 5）可作为花源代理；当前明确排除的 11 种风媒／自花授粉谷物不会计入花蜜来源。该机制是游戏玩法近似，不代表真实蜂蜜的植物学纯度鉴定。
