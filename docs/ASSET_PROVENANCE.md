# Asset provenance and publication checklist

This repository is a **fan-inspired experimental project**. Third-party online image collections are **visual research only** and are not redistributable project assets.

| Asset | File | Origin | Usage status |
| --- | --- | --- | --- |
| Blocky penguin texture | `src/main/resources/assets/gugugaga/textures/entity/observer.png` | Generated specifically for this prototype (solid color atlas) | Original placeholder; MIT project asset |
| Low-poly model | `client/ObserverModel.java` | Authored specifically for prototype | Original project source |
| Ambient sound | Vanilla Minecraft parrot ambient sound, referenced by resource only | Minecraft runtime | Not bundled |
| Gugu Gaga Endfield meme visual | No file imported | Online community images / creators | Reference only; **clear before packaging a recognizable adaptation** |
| Tomori-related remix audio | No file imported | Third-party audiovisual fan remix | Not used; no permission inferred |

Review before distribution:
1. Confirm the actual originator and license of each image/model/voice sample.
2. Obtain permission if adapting recognizable third-party protected visual design or sound.
3. Keep a verifiable attribution record including link, author, permission scope and date.
4. Never treat “free mod”, “fan tribute”, “AI generated”, or MIT for own code as replacement for third-party permission.
5. Use only independently made assets unless explicit terms allow the intended redistribution.
